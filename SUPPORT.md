# Support

WP24Horas open-source repositories are maintained as community engineering projects.

## Where to ask

- Use repository issues for reproducible bugs, focused feature requests and documentation problems.
- Use Discussions when a repository enables them and the topic is a broader usage question.
- Follow `SECURITY.md` for vulnerabilities; do not post exploitable details publicly.

## What to include

For a bug report, include:

- repository version or commit;
- WordPress/PHP versions when relevant;
- minimal steps to reproduce;
- expected and actual behavior;
- relevant logs with credentials and personal data removed.

## Boundaries

Open-source issue trackers are not a channel for client support, production incident response or private commercial product support. Do not post customer data, credentials or proprietary code.
